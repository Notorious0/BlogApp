# 📝 BlogApp – Full-Stack Blogging Platform (Node.js + MySQL)

**BlogApp** is a dynamic blogging platform developed using **Node.js**, **Express.js**, **EJS**, and **MySQL**.  
The application allows users to create, edit, and manage blog posts through a clean, server-rendered interface styled with **Bootstrap**.

## ⚙️ Tech Stack

- 🌐 **Node.js + Express.js** – Backend framework
- 🗃️ **MySQL** – Relational database
- 🖼️ **EJS** – Server-side templating engine
- 🎨 **Bootstrap** – Frontend styling
- 📦 **Express-session / body-parser** – Middleware tools

---


---

## 🚀 Features

- ✍️ Create, read, update, delete (CRUD) blog posts
- 👥 User registration & login system (if implemented)
- 🧠 Server-side rendering with EJS
- 🖌️ Responsive design with Bootstrap
- 💾 MySQL-powered data persistence

## 🔧 Installation

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/BlogApp.git
cd BlogApp




2. Install dependencies
npm install
3. Configure database
Create a MySQL database and update your connection settings in models/db.js or .env.
4. Start the application
node app.js
